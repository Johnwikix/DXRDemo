# ComputeSharp RayTraceShader → DXR 硬件加速移植文档（Vortice.Windows + WinUI3）

## 一、可行性结论

**✅ 完全可行。** 当前项目的 `RayTraceShader` 是一个基于 Compute Shader 的 Monte Carlo 路径追踪器（球体场景），其核心逻辑（光线生成、求交、材质散射、渐进累积）可以完整映射到 DXR 管线的 Ray Generation / Closest Hit / Miss / Intersection Shader 中。Vortice.Windows 已提供完整的 `ID3D12Device5` DXR 绑定，且社区已有成熟的 C# DXR 示例（[CSharpDirectXRaytracing](https://github.com/Jorgemagic/CSharpDirectXRaytracing)、[D3D12SampleRaytracerSharp](https://github.com/CAMongrel/D3D12SampleRaytracerSharp)）可直接参考。

## 四、DXR 管线设计

### 4.1 着色器映射

| 原 Compute Shader 逻辑   | DXR 着色器                            | HLSL 入口              |
| ------------------------ | ------------------------------------- | ---------------------- |
| 相机射线生成 + UV 计算   | **Ray Generation Shader**             | `RayGen()`             |
| 球体求交 (`HitSphere`)   | **Intersection Shader**（程序化几何） | `IntersectionSphere()` |
| 材质散射 + 光照计算      | **Closest Hit Shader**                | `ClosestHit()`         |
| 天空颜色 (`GetSkyColor`) | **Miss Shader**                       | `Miss()`               |
| 阴影检测 (`ShadowHit`)   | **Shadow Ray** + Miss Shader          | `ShadowMiss()`         |

### 4.2 HLSL 文件结构

```
Shaders/DXR/
├── RayTrace.hlsl          ← 主 DXR library（所有 shader 入口）
├── SceneData.hlsli        ← 共享结构体 / 常量
└── (编译产物) RayTrace.dxil
```

### 4.3 核心 HLSL 代码（RayTrace.hlsl）

```hlsl
// RayTrace.hlsl - DXR Library (compile with: dxc -T lib_6_3)
#include "SceneData.hlsli"

// ─── Resources ───────────────────────────────────────────
RaytracingAccelerationStructure SceneBVH : register(t0);
RWTexture2D<float4> RenderTarget : register(u0);
RWTexture2D<float4> PrevFrame : register(u1);
ConstantBuffer<SceneConstants> Scene : register(b0);

// ─── Payloads ────────────────────────────────────────────
//
// 总大小固定 64 字节（对齐到 D3D12_RAYTRACING_MAX_PAYLOAD_SIZE 边界）：
//   float3 color        : 12 B
//   float3 throughput   : 12 B
//   float3 nextOrigin   : 12 B  ← ClosestHit 写入，RayGen 取回
//   float3 nextDirection: 12 B  ← 同上
//   uint   rngState     :  4 B
//   int    remainingBounces :  4 B
//   int    hasHit       :  4 B  ← 1=命中(需要继续), 0=逸出/吸收(终止)
//   int    _pad         :  4 B
// 总计 64 B，与 ShaderConfig 的 MaxPayloadSizeInBytes 对齐。
struct PathTracePayload {
    float3 color;
    float3 throughput;
    float3 nextOrigin;
    float3 nextDirection;
    uint   rngState;
    int    remainingBounces;
    int    hasHit;
    int    _pad;
};

struct ShadowPayload {
    bool hit;
};

// ─── RNG (PCG) ───────────────────────────────────────────
uint PcgHash(uint state) {
    uint old = state;
    state = old * 747796405u + 2891336453u;
    uint word = ((old >> ((old >> 28) + 4)) ^ old) * 277803737u;
    return (word >> 22) ^ word;
}

float RandomFloat(inout uint state) {
    state = PcgHash(state);
    return float(state >> 8) / 16777215.0;
}

float3 RandomUnitVector(inout uint state) {
    float theta = RandomFloat(state) * 6.28318530717;
    float z = RandomFloat(state) * 2.0 - 1.0;
    float a = sqrt(1.0 - z * z);
    return float3(a * cos(theta), a * sin(theta), z) * sqrt(RandomFloat(state));
}

// ─── Ray Generation ──────────────────────────────────────
[shader("raygeneration")]
void RayGen() {
    uint2 pixel = DispatchRaysIndex().xy;
    uint2 dims  = DispatchRaysDimensions().xy;
    
    if (pixel.x >= (uint)Scene.Resolution.x || pixel.y >= (uint)Scene.Resolution.y)
        return;
    
    float2 fragCoord = float2(pixel.x + 0.5, Scene.Resolution.y - (pixel.y + 0.5));
    float2 uv = fragCoord / Scene.Resolution;
    
    // Camera setup (orbit)
    float2 mousePos = Scene.Mouse / Scene.Resolution;
    if (mousePos.x == 0.0 && mousePos.y == 0.0)
        mousePos = float2(0.55, 0.2);
    
    float dist = Scene.CameraDistance;
    float cx = cos(mousePos.x * 10.0) * dist;
    float cz = sin(mousePos.x * 10.0) * dist;
    float cy = mousePos.y * 10.0;
    
    float3 origin = float3(cx, cy, cz);
    float3 lookAt = float3(0, 1, 0);
    float3 up = float3(0, 1, 0);
    
    float fov = 80.0;
    float ratio = Scene.Resolution.x / Scene.Resolution.y;
    float halfW = tan(fov * 3.14159265 / 360.0);
    float halfH = halfW / ratio;
    
    float3 w = normalize(origin - lookAt);
    float3 u = normalize(cross(up, w));
    float3 v = cross(w, u);
    
    float3 lowerLeft = origin - u * halfW - v * halfH - w;
    float3 horizontal = u * halfW * 2.0;
    float3 vertical = v * halfH * 2.0;
    
    // RNG init
    uint rngState = pixel.x * 73856093 + pixel.y * 19349663 
                  + (uint)(Scene.Time * 1000.0) * 16777619 
                  + Scene.Frame * 83492791;
    
    float3 color = float3(0, 0, 0);
    const int SAMPLES = 4;
    
    for (int s = 0; s < SAMPLES; s++) {
        float2 jitter = float2(RandomFloat(rngState), RandomFloat(rngState));
        float3 dir = lowerLeft - origin
                   + horizontal * (uv.x + jitter.x / Scene.Resolution.x)
                   + vertical   * (uv.y + jitter.y / Scene.Resolution.y);
        
        // Path trace loop
        float3 rayOrigin = origin;
        float3 rayDir = normalize(dir);
        float3 accum = float3(0, 0, 0);
        float3 mask = float3(1, 1, 1);
        
        for (int bounce = 0; bounce < 10; bounce++) {
            PathTracePayload payload;
            payload.color = float3(0, 0, 0);
            payload.throughput = mask;
            payload.nextOrigin = float3(0, 0, 0);
            payload.nextDirection = float3(0, 0, 0);
            payload.rngState = rngState;
            payload.remainingBounces = 10 - bounce;
            payload.hasHit = 0;
            
            RayDesc ray;
            ray.Origin = rayOrigin;
            ray.Direction = rayDir;
            ray.TMin = 0.001;
            ray.TMax = 5000.0;
            
            TraceRay(SceneBVH, RAY_FLAG_NONE, 0xFF, 0, 0, 0, ray, payload);
            
            rngState = payload.rngState;
            accum += payload.color;
            
            // 终止条件：光线逸出 (Miss) 或剩余 bounces 耗尽
            if (payload.hasHit == 0 || payload.remainingBounces <= 0)
                break;
            
            // 取回下一跳射线
            rayOrigin  = payload.nextOrigin;
            rayDir     = payload.nextDirection;
            mask       = payload.throughput;
        }
        
        color += accum;
    }
    
    color /= SAMPLES;
    
    // Gamma correction
    color = pow(color, float3(1.0/2.2, 1.0/2.2, 1.0/2.2));
    
    // Progressive accumulation
    float4 prevColor = PrevFrame[pixel];
    float weight = Scene.Frame < 1 ? 1.0 : min(float(Scene.Frame + 1), 100.0);
    float3 finalColor = lerp(prevColor.rgb, color, 1.0 / weight);
    
    RenderTarget[pixel] = float4(finalColor, 1.0);
}

// ─── Intersection Shader (Procedural Sphere) ─────────────
[shader("intersection")]
void IntersectionSphere() {
    // Sphere data from InstanceID / GeometryIndex
    SphereData sphere = Spheres[GeometryIndex()];
    
    float3 oc = WorldRayOrigin() - sphere.Center;
    float a = dot(WorldRayDirection(), WorldRayDirection());
    float b = dot(oc, WorldRayDirection());
    float c = dot(oc, oc) - sphere.Radius * sphere.Radius;
    float disc = b * b - a * c;
    
    if (disc < 0.0)
        return;
    
    float sqrtDisc = sqrt(disc);
    float t = (-b - sqrtDisc) / a;
    if (t < RayTMin() || t > RayTMax()) {
        t = (-b + sqrtDisc) / a;
        if (t < RayTMin() || t > RayTMax())
            return;
    }
    
    ReportHit(t, 0, (Attributes){0});
}

// ─── Closest Hit Shader ──────────────────────────────────
[shader("closesthit")]
void ClosestHit(inout PathTracePayload payload, Attributes attr) {
    uint sphereIdx = GeometryIndex();
    SphereData sphere = Spheres[sphereIdx];
    
    float3 hitPos = WorldRayOrigin() + WorldRayDirection() * RayTCurrent();
    float3 normal = normalize(hitPos - sphere.Center);
    // 负半径表示内表面（玻璃气泡），需翻转法线
    if (sphere.Radius < 0.0)
        normal = -normal;
    
    int   matType  = sphere.MaterialType;
    float3 albedo  = sphere.Albedo;
    float matParam = sphere.MaterialParam;
    
    // 太阳方向光（带阴影）
    float3 sunDir   = normalize(float3(1.0, 0.8, -0.5));
    float3 sunColor = float3(3.0, 2.8, 2.5);
    float ndotl = dot(normal, sunDir);
    
    if (ndotl > 0.0) {
        ShadowPayload shadowPayload;
        shadowPayload.hit = false;
        
        RayDesc shadowRay;
        shadowRay.Origin    = hitPos + normal * 0.001;
        shadowRay.Direction = sunDir;
        shadowRay.TMin      = 0.001;
        shadowRay.TMax      = 5000.0;
        
        TraceRay(SceneBVH, RAY_FLAG_ACCEPT_FIRST_HIT_AND_END_SEARCH,
                 0xFF, 0, 1, 1, shadowRay, shadowPayload);
        
        if (!shadowPayload.hit) {
            float3 V = -normalize(WorldRayDirection());
            float3 H = normalize(V + sunDir);
            float ndoth = max(dot(normal, H), 0.0);
            
            if (matType == 0) { // Lambertian
                payload.color += payload.throughput * albedo * sunColor * ndotl * (1.0 / 3.14159265);
            } else if (matType == 1) { // Metal
                float roughness = matParam * matParam + 0.001;
                float spec = pow(ndoth, 1.0 / roughness);
                payload.color += payload.throughput * albedo * sunColor * spec * ndotl * 0.5;
            } else { // Dielectric
                float fresnel = Schlick(ndoth, matParam);
                payload.color += payload.throughput * sunColor * pow(ndoth, 10.0) * fresnel;
            }
        }
    }
    
    // 材质散射 → 计算下一跳射线
    float3 scatterDir = float3(0, 0, 0);
    bool   terminated = false;
    
    if (matType == 0) { // Lambertian: 法线半球采样
        scatterDir = normal + RandomUnitVector(payload.rngState);
        payload.throughput *= albedo;
    } else if (matType == 1) { // Metal: 反射 + 粗糙度扰动
        float3 reflected = reflect(WorldRayDirection(), normal);
        scatterDir = reflected + RandomUnitVector(payload.rngState) * matParam;
        if (dot(scatterDir, normal) <= 0.0) {
            terminated = true;  // 光线被表面吸收
        } else {
            payload.throughput *= albedo;
        }
    } else { // Dielectric: Fresnel 选反射/折射
        float3 reflected = reflect(WorldRayDirection(), normal);
        float eta, cosine, dt = dot(WorldRayDirection(), normal);
        float3 outwardNormal;
        
        if (dt > 0.0) {  // 从内部射出
            outwardNormal = -normal;
            eta = matParam;
            cosine = eta * dt;
        } else {           // 从外部进入
            outwardNormal = normal;
            eta = 1.0 / matParam;
            cosine = -dt;
        }
        
        float3 refracted = refract(WorldRayDirection(), outwardNormal, eta);
        float reflectProb;
        if (dot(refracted, refracted) > 0.0)
            reflectProb = Schlick(cosine, matParam);
        else
            reflectProb = 1.0;  // 全反射
        
        if (RandomFloat(payload.rngState) < reflectProb) {
            scatterDir = reflected;
        } else {
            scatterDir = refracted;
        }
        // 玻璃不衰减 throughput
    }
    
    // 写入下一跳状态到 payload（payload 递推方案）
    if (!terminated && dot(scatterDir, scatterDir) > 1e-6) {
        payload.nextOrigin    = hitPos + normal * 0.001;
        payload.nextDirection = normalize(scatterDir);
        payload.hasHit        = 1;
    } else {
        payload.hasHit = 0;  // 终止路径
    }
    
    payload.remainingBounces--;
}

// ─── Miss Shader ─────────────────────────────────────────
[shader("miss")]
void Miss(inout PathTracePayload payload) {
    float3 dir = normalize(WorldRayDirection());
    float t = dir.y * 0.5 + 0.5;
    float3 sky = lerp(float3(0.01, 0.01, 0.04), float3(0.3, 0.5, 0.8), t);
    
    float3 sunDir = normalize(float3(1.0, 0.8, -0.5));
    float sunAngle = max(dot(dir, sunDir), 0.0);
    sky += float3(3.0, 2.8, 2.5) * pow(sunAngle, 200.0) * 0.5;
    
    sky *= 0.3;
    sky = pow(sky, float3(2.2, 2.2, 2.2));
    
    payload.color += payload.throughput * sky;
    payload.hasHit = 0;             // 终止路径（payload 递推标志）
    payload.remainingBounces = 0;
}

// ─── Shadow Miss Shader ──────────────────────────────────
[shader("miss")]
void ShadowMiss(inout ShadowPayload payload) {
    payload.hit = false;
}

// ─── Shadow Closest Hit ──────────────────────────────────
[shader("closesthit")]
void ShadowClosestHit(inout ShadowPayload payload, Attributes attr) {
    payload.hit = true;
}
```

```hlsl
#define SCENE_DATA_HLSLI

    float2 Resolution;
    float2 Mouse;

};

struct SphereData {
    float3 Center;
    float  Radius;
    float3 Albedo;
    int    MaterialType;  // 0=Lambertian, 1=Metal, 2=Dielectric
    float  MaterialParam; // roughness or IOR
    float3 _pad;
};

struct Attributes {
    uint dummy;
};

// Sphere buffer (StructuredBuffer in root signature)
StructuredBuffer<SphereData> Spheres : register(t1);

float Schlick(float cosine, float ior) {
    float r0 = (1.0 - ior) / (1.0 + ior);
    r0 = r0 * r0;
    return r0 + (1.0 - r0) * pow(1.0 - cosine, 5.0);
}

#endif
```

### 4.5 Acceleration Structure 拓扑方案

**采用方案：单 BLAS 包含 5 个 AABB 几何 + 单 TLAS instance。**

#### 设计

```
BLAS (Bottom-Level)
  └─ GeometryDescriptions[5] : RaytracingAabbGeometryDescription  ← 5 个球体
       └─ 每个描述含一个 AABB（球体包围盒）

TLAS (Top-Level)
  └─ InstanceDescriptions[1] : RaytracingInstanceDescription
       └─ Transform    = Identity
       └─ InstanceID   = 0
       └─ InstanceMask = 0xFF
       └─ InstanceContributionToHitGroupIndex = 0
       └─ AccelerationStructure = BLAS.GPUVirtualAddress
```

#### Shader Table 简化

由于所有几何共享同一组 Intersection / ClosestHit / Miss Shader，**Shader Table 只需 1 条 HitGroup 记录**：

| Record 索引 | Shader 名称 | 备注 |
|---|---|---|
| 0 | `RayGen` | 主光线生成 |
| 1 | `Miss` | 主射线天空（payload 写入终止标志） |
| 2 | `ShadowMiss` | 阴影射线天空 |
| 3 | `HitGroup_Sphere` | 唯一 HitGroup，5 个球体共用 |

#### HLSL 端：用 `GeometryIndex()` 选择球体

```hlsl
[shader("intersection")]
void IntersectionSphere() {
    uint sphereIdx = GeometryIndex();   // 0..4，对应 5 个球体
    SphereData sphere = Spheres[sphereIdx];
    // ... AABB 求交
    ReportHit(t, 0, (Attributes){0});
}

[shader("closesthit")]
void ClosestHit(inout PathTracePayload payload, Attributes attr) {
    uint sphereIdx = GeometryIndex();   // 同一索引选球体
    SphereData sphere = Spheres[sphereIdx];
    // ... 材质散射
}
```

#### 与 §5.3"5 BLAS 独立方案"对比

| 方案 | 优点 | 缺点 |
|---|---|---|
| **单 BLAS 多 AABB**（**采用**） | 1 条 HitGroup 记录、shader table 更小、构建开销低 | GeometryIndex 隐含"按声明顺序索引"约定 |
| 5 BLAS 独立 | TLAS instance 显式对应球体 | 5 条 HitGroup 记录、构建 5 次 BLAS |

> 备注：ComputeSharp 原实现是软件循环 `if (HitSphere(...)) { ... }` 按顺序遍历 5 个静态常数球体；我们用 DXR 时改为 **GeometryIndex 隐式按声明顺序**，语义等价。

```csharp
public sealed class DxrRenderer : IDisposable
{

    private ID3D12CommandQueue _commandQueue = null!;
    private ID3D12GraphicsCommandList4 _commandList = null!;
    private ID3D12StateObject _rtPipelineState = null!;

    public void Initialize(IntPtr hwnd, int width, int height)
    {
        // 1. 创建 D3D12 Device (需要 DXR 支持)
        CreateDevice();
        
        // 2. 验证 DXR 支持
        var options5 = _device.CheckFeatureSupport<FeatureDataRaytracingOptions>(Feature.RaytracingOptions);
        if (options5.RaytracingTier == RaytracingTier.NotSupported)
            throw new NotSupportedException("GPU does not support DXR");
        
        // 3. 创建 Command Queue + Command List
        CreateCommandObjects();
        
        // 4. 编译 HLSL → DXIL Library
        CompileShaders();
        
        // 5. 创建 Root Signature
        CreateRootSignature();
        
        // 6. 构建 Acceleration Structures
        BuildAccelerationStructures();
        
        // 7. 创建 RT Pipeline State
        CreateRaytracingPipelineState();
        
        // 8. 构建 Shader Table
        BuildShaderTable();
        
        // 9. 创建输出纹理 + 上传缓冲区
        CreateResources(width, height);
        
        // 10. 创建 SwapChain (关联 WinUI3 SwapChainPanel)
        CreateSwapChain(hwnd, width, height);
    }
    
    public void Render(float time, float mouseX, float mouseY, float cameraDist, int frame)
    {
        // 更新常量缓冲区
        UpdateConstants(time, mouseX, mouseY, cameraDist, frame);
        
        // 记录命令
        _commandList.Reset(_commandAllocator);
        
        // 设置 RT Pipeline State
        _commandList.SetPipelineState1(_rtPipelineState);
        _commandList.SetComputeRootSignature(_rootSignature);
        
        // 绑定资源
        _commandList.SetComputeRootShaderResourceView(0, _tlasResource.GPUVirtualAddress);
        _commandList.SetComputeRootUnorderedAccessView(1, _outputTexture.GPUVirtualAddress);
        _commandList.SetComputeRootUnorderedAccessView(2, _prevFrameTexture.GPUVirtualAddress);
        _commandList.SetComputeRootConstantBufferView(3, _constantBuffer.GPUVirtualAddress);
        _commandList.SetComputeRootShaderResourceView(4, _sphereBuffer.GPUVirtualAddress);
        
        // DispatchRays
        _commandList.DispatchRays(new DispatchRaysDescription(
            _shaderTable.GPUVirtualAddress, shaderTableSize,
            (uint)_width, (uint)_height, 1));
        
        // 资源转换 + Present
        _commandList.Close();
        _commandQueue.ExecuteCommandList(_commandList);
        _swapChain.Present(1, PresentFlags.None);
    }
}
```

### 5.3 Acceleration Structure 构建（球体场景）

```csharp
private void BuildAccelerationStructures()
{
    // 方案A：程序化几何（Intersection Shader）— 推荐用于球体
    // 每个球体作为一个 AABB 几何描述
    
    var spheres = new[] {
        new SphereData { Center = new(0,1,0),    Radius = 1.0f,    MatType = 0, Albedo = new(0,0.9f,0.05f), MatParam = 0 },
        new SphereData { Center = new(0,1,2.5f), Radius = 1.0f,    MatType = 1, Albedo = new(0.9f,0.9f,0.9f), MatParam = 0.01f },
        new SphereData { Center = new(0,1,-2.5f),Radius = 1.0f,    MatType = 2, Albedo = new(0,0,0), MatParam = 1.5f },
        new SphereData { Center = new(0,1,-2.5f),Radius = -0.92f,  MatType = 2, Albedo = new(0.9f,0.9f,0.9f), MatParam = 1.5f },
        new SphereData { Center = new(0,-1000,0),Radius = 1000.0f, MatType = 0, Albedo = new(0.9f,0.9f,0.9f), MatParam = 0 },
    };
    
    // 上传球体数据到 StructuredBuffer
    _sphereBuffer = CreateStructuredBuffer(spheres);
    
    // BLAS: 使用 AABB 描述每个球体的包围盒
    var aabbs = spheres.Select(s => new RaytracingAabb(
        s.Center.X - Math.Abs(s.Radius), s.Center.Y - Math.Abs(s.Radius), s.Center.Z - Math.Abs(s.Radius),
        s.Center.X + Math.Abs(s.Radius), s.Center.Y + Math.Abs(s.Radius), s.Center.Z + Math.Abs(s.Radius)
    )).ToArray();
    
    // 构建 BLAS (procedural geometry with AABBs)
    var blasInputs = new RaytracingGeometryDescriptions {
        // ... AABB geometry description
    };
    
    var blasDesc = new BuildRaytracingAccelerationStructureInputs {
        Type = RaytracingAccelerationStructureType.BottomLevel,
        Flags = AccelerationStructureBuildFlags.None,
        GeometryDescriptions = blasInputs,
    };
    
    // TLAS: 每个球体一个 Instance
    var instances = spheres.Select((s, i) => new RaytracingInstanceDescription {
        Transform = Matrix4x4.Identity,
        InstanceID = (uint)i,
        InstanceMask = 0xFF,
        InstanceContributionToHitGroupIndex = (uint)i,
        Flags = RaytracingInstanceFlags.None,
        AccelerationStructure = _blasResource.GPUVirtualAddress,
    }).ToArray();
    
    // 构建 TLAS
    var tlasDesc = new BuildRaytracingAccelerationStructureInputs {
        Type = RaytracingAccelerationStructureType.TopLevel,
        Flags = AccelerationStructureBuildFlags.None,
        InstanceDescriptions = instances,
    };
    
    // 分配 + 构建（需要 scratch buffer）
    BuildAS(blasDesc, out _blasResource);
    BuildAS(tlasDesc, out _tlasResource);
}
```

## 八、Shader Table 构建

```csharp
private void BuildShaderTable()
{
    // Shader Table 布局:
    // [RayGen Record] [Miss Record(s)] [HitGroup Record(s)]
    
    var rayGenId = _rtPipelineInfo.GetShaderIdentifier("RayGen");
    var missId = _rtPipelineInfo.GetShaderIdentifier("Miss");
    var shadowMissId = _rtPipelineInfo.GetShaderIdentifier("ShadowMiss");
    var hitGroupId = _rtPipelineInfo.GetShaderIdentifier("HitGroup_Sphere");
    var shadowHitId = _rtPipelineInfo.GetShaderIdentifier("HitGroup_Shadow");
    
    // 每条记录 32 bytes (shader identifier) + local root args
    const int recordSize = 64; // 对齐到 D3D12_SHADER_IDENTIFIER_SIZE_IN_BYTES
    
    // 分配 upload buffer
    int tableSize = recordSize * 5; // 1 raygen + 2 miss + 2 hitgroup
    _shaderTable = CreateUploadBuffer(tableSize);
    
    // 写入 shader identifiers
    var mapped = _shaderTable.Map(0);
    // RayGen record
    WriteShaderRecord(mapped, 0 * recordSize, rayGenId);
    // Miss records
    WriteShaderRecord(mapped, 1 * recordSize, missId);
    WriteShaderRecord(mapped, 2 * recordSize, shadowMissId);
    // HitGroup records
    WriteShaderRecord(mapped, 3 * recordSize, hitGroupId);
    WriteShaderRecord(mapped, 4 * recordSize, shadowHitId);
    _shaderTable.Unmap(0);
}
```

## 九、Root Signature 设计

### 9.1 槽位交叉对照表（C# ↔ HLSL 严格一致）

| Root Param 索引 | C# 类型 | 寄存器槽位 | HLSL 声明 | 用途 |
|---|---|---|---|---|
| 0 | `SRV` | `t0` | `RaytracingAccelerationStructure SceneBVH` | TLAS（顶层加速结构） |
| 1 | `UAV` | `u0` | `RWTexture2D<float4> RenderTarget` | 当前帧输出 |
| 2 | `UAV` | `u1` | `RWTexture2D<float4> PrevFrame`   | 上一帧（渐进累积） |
| 3 | `CBV` | `b0` | `ConstantBuffer<SceneConstants> Scene` | 每帧常量 |
| 4 | `SRV` | `t1` | `StructuredBuffer<SphereData> Spheres` | 球体场景数据 |

> **重要**：HLSL §4.3 中的 `register(t0/u0/u1/b0/t1)` 与上表的"寄存器槽位"列**一一对应**，根参数顺序变更时必须同步修改 HLSL 端。

### 9.2 实现代码

```csharp
private void CreateRootSignature()
{
    var parameters = new RootParameter[] {
        // [0] t0: Acceleration Structure (SRV)
        RootParameter.ShaderResourceView(0, ShaderVisibility.All),
        // [1] u0: Render Target (UAV)
        RootParameter.UnorderedAccessView(0, ShaderVisibility.All),
        // [2] u1: Previous Frame (UAV)
        RootParameter.UnorderedAccessView(1, ShaderVisibility.All),
        // [3] b0: Scene Constants (CBV)
        RootParameter.ConstantBufferView(0, ShaderVisibility.All),
        // [4] t1: Sphere Data (SRV - StructuredBuffer)
        RootParameter.ShaderResourceView(1, ShaderVisibility.All),
    };
    
    // 注意：光线追踪管线不需要 InputAssembler；用 None 标志
    var desc = new RootSignatureDescription(
        RootSignatureFlags.None,
        parameters,
        staticSamplers: null);
    
    var blob = D3D12SerializeRootSignature(desc);
    _rootSignature = _device.CreateRootSignature<ID3D12RootSignature>(blob);
}
```

### 10.4 渐进累积策略

DXR 本身不做时间累积。保持与原项目相同的策略：

- 维护 `PrevFrame` 纹理（UAV）
- 每帧在 RayGen 中读取 `PrevFrame`，按 `1/(frame+1)` 权重混合
- 相机移动时重置 `frame = 0`

### 10.5 球体 vs 三角形几何

| 方案                                        | 优点                     | 缺点                           |
| ------------------------------------------- | ------------------------ | ------------------------------ |
| **程序化几何 (AABB + Intersection Shader)** | 精确球体、代码简洁       | 需要自定义 intersection shader |
| 三角形网格逼近                              | 无需 intersection shader | 需要生成球体网格、不够精确     |

**推荐方案A**（程序化几何），与原项目的球体求交逻辑一一对应。
