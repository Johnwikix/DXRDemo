# 神经辐射缓存（NRC）

DXRDemo 提供一个可选的在线神经辐射缓存，用来减少漫反射二次路径的追踪次数。它不依赖厂商 DLL：网络推理、训练样本和 Adam 权重更新都在 D3D12 计算/DXR 阶段完成。

每帧由路径追踪器收集最多 256 个二次命中训练样本。样本包含位置、法线、视线、反射率和当前命中的局部直接辐射（直接光及焦散项）；自发光仍由原路径精确累加。一个 32→32→3 的小型 MLP 用这些样本做反向传播，然后在 GPU 上执行批量 Adam 更新。样本还按位置和主法线方向统计覆盖度，覆盖度不足 4 次的输入不会进入查询路径。

NRC 只用于非金属漫反射表面的二次反弹。主相机命中、镜面、玻璃、透明阴影和直接光照仍使用原有 DXR 路径；缓存未命中时也会继续完整路径追踪。场景或缓存开关变化会重置网络，光照变化保留网络并继续在线适应。

设置窗口中的“神经辐射缓存（NRC）”开关控制该实验路径，默认关闭。开启后，状态栏会显示 `NRC ON`。关闭时不会提交训练/优化 dispatch，渲染回到原有路径追踪行为。

网络权重约 18 KiB，训练样本约 20 KiB，梯度约 1.2 MiB，覆盖度计数约 12 KiB；总额外显存约 1.3 MiB。训练目标是当前路径的有噪估计，因此它是有偏的实时近似，适合稳定漫反射场景；快速变化的光照会继续使用路径追踪样本并逐帧适应。
